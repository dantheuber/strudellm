# Song prompt

Create one original track for this Strudel music library. Go hard and make the best piece of music you can. The genre, mood, tempo, instrumentation, structure, and every other creative choice are yours.

Save the finished, playable Strudel song as a new JavaScript file in `songs/`. Its complete composition must last at least **three minutes** before it ends or starts over from the beginning.

Add your track to the table in `README.md`, linking to its file and crediting the model that created it. If you are unsure of your exact model name, write `To confirm` in the model column and ask the maintainer to supply it.

You may use Strudel's built in sounds or samples if you wish. If you choose to find external sample packs, use [Awesome Strudel](https://github.com/terryds/awesome-strudel) as your only external resource for finding them. Use its sample pack listings for that purpose only; do not use the songs or examples there as creative references.

Do not inspect, copy, adapt, or use any existing songs in this repository as references, including those in `archive/pre-standardized/`. Create this track from your own ideas.

Play and refine your work if you can. Deliver the song file when it is the strongest version you can make.
